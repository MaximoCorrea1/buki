# Shelfy 1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn a working prototype into Shelfy 1.0 — named, branded, legible at a hundred books, able to finish a book as well as catch one, and ready to submit to the Chrome Web Store.

**Architecture:** No new dependencies and no new runtime surfaces. The shelf palette inverts to a light ground with coloured spines, driven entirely by CSS custom properties so dark mode is a token swap. Two new pure modules (`buyLink`, and the `read` intent in existing storage) carry all the testable logic; everything else is markup, CSS and documents.

**Tech Stack:** TypeScript 5.9, MV3, vitest 3.2.7, esbuild. Icons are generated by a dependency-free PNG writer in `tools/make-icons.mjs`.

Source spec: `docs/superpowers/specs/2026-07-29-shelfy-1-0-design.md`

## Global Constraints

- **Run tests with `./node_modules/.bin/vitest run`**; typecheck with `node node_modules/typescript/bin/tsc --noEmit`; build with `node build.mjs`. `npm run <script>` and `npx` both fail from Git Bash via the cmd.exe shim.
- **No new npm dependencies.**
- **Never rename a storage key.** `savedBooks`, `recognitionLog` and `visionSettings` stay exactly as they are — renaming any of them silently destroys every existing user's shelf. Interfaces may be renamed; keys may not.
- **Palette, exactly:** `--paper #F4F2FB`, `--board #E2DEF0`, `--ink #171526`, `--muted #6B6785`, `--gilt #fae636`, cloth `#ff6352 #FFB020 #2FB88A #6C7BFF #B265D9`.
- **`--gilt` is graphic-only.** At ~1.2:1 on `--paper` it is invisible as text and useless as a focus ring. Focus rings use `--ink`; accent text uses cloth periwinkle `#6C7BFF`.
- **Spine cords are a white highlight over a dark shadow**, never flat gilt — a single gold line vanishes on marigold cloth, which is how the first shelf design shipped with its signature detail invisible.
- **Only `transform`, `opacity` and `filter` animate.** Durations under 300ms, easing `cubic-bezier(.23,1,.32,1)`, and `prefers-reduced-motion` respected.
- All logging is prefixed `[Shelfy]`.
- The affiliate relationship must be disclosed in the popup, the store listing and the privacy policy.

- [ ] **Step 1: Switch the PNG writer to RGBA**

In `tools/make-icons.mjs`, the existing `crc32` and `chunk` helpers stay untouched. Replace everything from `const SIZES` down to the final loop with:

```js
const SIZES = [16, 32, 48, 128];

// Three spines of unequal height, crossed by one cord. At 16px this reduces to three
// coloured bars and a gold line, which is the whole test: a mark that survives the
// toolbar is a mark.
const CLOTH = [
  [0xff, 0x63, 0x52], // coral
  [0x2f, 0xb8, 0x8a], // jade
  [0x6c, 0x7b, 0xff], // periwinkle
];
const GILT = [0xfa, 0xe6, 0x36];

/** Transparent ground, so the mark reads on a light or a dark toolbar alike. */
function png(size) {
  const u = size / 16; // one unit = one pixel at the smallest size
  const px = (n) => Math.round(n * u);

  const spines = [
    { x0: px(2), x1: px(6), y0: px(3) },
    { x0: px(6.5), x1: px(10.5), y0: px(1.5) },
    { x0: px(11), x1: px(15), y0: px(4) },
  ];
  const floor = px(14.5);
  const cordY = px(9);
  const cordH = Math.max(1, px(1.5));

  const raw = Buffer.alloc(size * (size * 4 + 1));
  let p = 0;
  for (let y = 0; y < size; y++) {
    raw[p++] = 0; // PNG filter: none
    for (let x = 0; x < size; x++) {
      const hit = spines.findIndex((s) => x >= s.x0 && x < s.x1 && y >= s.y0 && y < floor);
      if (hit === -1) {
        raw[p++] = 0;
        raw[p++] = 0;
        raw[p++] = 0;
        raw[p++] = 0; // transparent
        continue;
      }
      const onCord = y >= cordY && y < cordY + cordH;
      const colour = onCord ? GILT : CLOTH[hit];
      raw[p++] = colour[0];
      raw[p++] = colour[1];
      raw[p++] = colour[2];
      raw[p++] = 0xff;
    }
  }

  const ihdr = Buffer.alloc(13);
  ihdr.writeUInt32BE(size, 0);
  ihdr.writeUInt32BE(size, 4);
  ihdr[8] = 8; // bit depth
  ihdr[9] = 6; // colour type: truecolour + alpha
  return Buffer.concat([
    Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]),
    chunk('IHDR', ihdr),
    chunk('IDAT', deflateSync(raw, { level: 9 })),
    chunk('IEND', Buffer.alloc(0)),
  ]);
}

await mkdir('icons', { recursive: true });
for (const size of SIZES) {
  await writeFile(`icons/icon${size}.png`, png(size));
  console.log(`icons/icon${size}.png`);
}
```

```ts
import type { Book } from '../recognizer/types';

export type Store = 'amazon' | 'bookshop';

export interface Affiliate {
  amazonTag: string;
  bookshopId: string;
}

/**
 * Shelfy's own affiliate identifiers. Public by nature - they ship in the bundle, as
 * every affiliate link on the web does.
 *
 * Both may be empty, and the links still work without them. That matters: a buy link
 * that only functions once an affiliate account exists cannot be tested before it ships.
 */
export const AFFILIATE: Affiliate = {
  amazonTag: '',
  bookshopId: '',
};

/**
 * A link to buy a book you have already decided to save.
 *
 * Amazon is searched rather than linked directly: OpenLibrary returns ISBN-13 as often as
 * ISBN-10, and only ISBN-10 doubles as an ASIN, so a `/dp/` link built from an ISBN-13 is
 * a 404. A search on the ISBN finds the book either way.
 */
export function buyLink(book: Book, store: Store, affiliate: Affiliate = AFFILIATE): string | null {
  const query = book.isbn || [book.title, book.author].filter(Boolean).join(' ').trim();
  if (!query) return null;

  if (store === 'bookshop') {
    // The /a/ path is what attributes the sale; without an id there is nothing to
    // attribute, so send the reader to the search they wanted anyway.
    return affiliate.bookshopId && book.isbn
      ? `https://bookshop.org/a/${affiliate.bookshopId}/${book.isbn}`
      : `https://bookshop.org/search?keywords=${encodeURIComponent(query)}`;
  }

  const url = new URL('https://www.amazon.com/s');
  url.searchParams.set('k', query);
  if (affiliate.amazonTag) url.searchParams.set('tag', affiliate.amazonTag);
  return url.toString();
}
```

/**
 * Does this book answer to what was typed? Title or author, case-insensitive - you
 * remember who wrote something as often as what it was called.
 *
 * Here rather than in the popup so it can be tested: `popup.ts` renders on import.
 */
export function matchesFilter(saved: SavedBook, needle: string): boolean {
  const trimmed = needle.trim().toLowerCase();
  if (!trimmed) return true;
  return `${saved.book.title} ${saved.book.author}`.toLowerCase().includes(trimmed);
}

const INTENTS: Intent[] = ['now', 'next', 'someday', 'read'];
const LABELS: Record<Intent, string> = {
  now: 'Reading now',
  next: 'Up next',
  someday: 'Someday',
  read: 'Finished',
};
const SOURCE_LABEL = { tweet: 'the post that sold you', page: 'where you found it' } as const;

/** Past this many books the shelf needs finding, not just scrolling. */
const FILTER_FROM = 15;

const CLOTH = ['#ff6352', '#FFB020', '#2FB88A', '#6C7BFF', '#B265D9'];

/**
 * Same book, same cloth, forever - derived from the book, not from insertion order.
 * djb2 rather than a naive *31: the simple version bunched real titles onto the same
 * two colours, which defeats the point of having a varied shelf.
 */
function clothFor(book: SavedBook['book']): string {
  const key = book.isbn ?? `${book.title}|${book.author}`;
  let hash = 5381;
  for (let i = 0; i < key.length; i++) hash = ((hash << 5) + hash + key.charCodeAt(i)) >>> 0;
  return CLOTH[hash % CLOTH.length] ?? CLOTH[0]!;
}

function coverFor(saved: SavedBook, cloth: string): HTMLElement {
  const initial = saved.book.title.trim()[0]?.toUpperCase() ?? '?';
  if (!saved.book.coverUrl) {
    const blank = document.createElement('div');
    blank.className = 'cover blank';
    blank.textContent = initial;
    return blank;
  }

  const img = document.createElement('img');
  img.className = 'cover';
  img.src = saved.book.coverUrl;
  img.alt = '';
  img.loading = 'lazy'; // a hundred rows must not fire a hundred requests at once
  // A cover that 404s should become the cloth block, not a broken-image glyph.
  img.addEventListener('error', () => {
    const blank = document.createElement('div');
    blank.className = 'cover blank';
    blank.style.setProperty('--cloth', cloth);
    blank.textContent = initial;
    img.replaceWith(blank);
  });
  return img;
}

function link(href: string, text: string): HTMLAnchorElement {
  const a = document.createElement('a');
  a.href = href;
  a.target = '_blank';
  a.rel = 'noreferrer';
  a.textContent = text;
  return a;
}

function renderBook(
  saved: SavedBook,
  index: number,
  store: Store,
  onChange: () => void,
): HTMLElement {
  const cloth = clothFor(saved.book);
  const row = document.createElement('div');
  row.className = 'spine';
  row.style.setProperty('--cloth', cloth);
  // Capped: a hundred books must not spend three seconds cascading in.
  row.style.animationDelay = `${Math.min(index, 8) * 28}ms`;

  const edge = document.createElement('div');
  edge.className = 'edge';

  const meta = document.createElement('div');
  meta.className = 'meta';

  const title = document.createElement('div');
  title.className = 'title';
  title.textContent = saved.book.title;
  meta.appendChild(title);

  if (saved.book.author) {
    const author = document.createElement('div');
    author.className = 'author';
    author.textContent = saved.book.author;
    meta.appendChild(author);
  }

  const links = document.createElement('div');
  links.className = 'links';
  // Only http(s): the source is browser-supplied today, but this keeps a future
  // paste/import path from putting a javascript: URL on the shelf.
  if (saved.source && /^https?:\/\//i.test(saved.source.url)) {
    links.appendChild(link(saved.source.url, SOURCE_LABEL[saved.source.kind]));
  }
  const buy = buyLink(saved.book, store);
  if (buy) {
    if (links.childElementCount) {
      const dot = document.createElement('span');
      dot.textContent = '·';
      links.appendChild(dot);
    }
    links.appendChild(link(buy, 'buy'));
  }
  if (links.childElementCount) meta.appendChild(links);

  const actions = document.createElement('div');
  actions.className = 'actions';

  if (saved.intent !== 'read') {
    const done = document.createElement('button');
    done.className = 'act';
    done.textContent = '✓';
    done.title = `Mark ${saved.book.title} as finished`;
    done.setAttribute('aria-label', `Mark ${saved.book.title} as finished`);
    done.addEventListener('click', async () => {
      done.disabled = true;
      try {
        // Finishing is not a wrong match, so it must never flag the recognition.
        await library.add(saved.book, 'read', saved.source);
        onChange();
      } catch (err) {
        console.error('[Shelfy] could not mark it finished', err);
        done.disabled = false;
      }
    });
    actions.appendChild(done);
  }

  const remove = document.createElement('button');
  remove.className = 'act';
  remove.textContent = '×';
  remove.title = `Remove ${saved.book.title}`;
  remove.setAttribute('aria-label', `Remove ${saved.book.title}`);
  remove.addEventListener('click', async () => {
    remove.disabled = true;
    try {
      await library.remove(saved.id);
      // Deleting a wrong match is both the fix and the measurement. The background
      // decides whether this was soon enough after saving to count against the
      // recognizer, rather than you simply changing your mind about reading it.
      //
      // Started here but awaited below: waking a sleeping service worker can take long
      // enough that a re-render would read the old kept rate and appear not to have
      // noticed the delete. The collapse plays during the round trip either way.
      const flagged = chrome.runtime
        .sendMessage({ type: 'markWrong', savedId: saved.id } satisfies BackgroundRequest)
        .catch((err: unknown) => console.error('[Shelfy] could not flag the match', err));

      row.classList.add('leaving');
      setTimeout(() => void flagged.then(onChange), 170);
    } catch (err) {
      console.error('[Shelfy] remove failed', err);
      remove.disabled = false;
    }
  });
  actions.appendChild(remove);

  row.append(edge, coverFor(saved, cloth), meta, actions);
  return row;
}

/**
 * One line, in the masthead: `23 caught · 78% kept`. The kept rate is the only number
 * worth watching, and it costs nothing to produce - deleting a wrong match is already
 * the fix.
 */
async function renderStats(shelfCount: number): Promise<void> {
  const el = document.getElementById('count');
  if (!el) return;

  let events: RecognitionEvent[] = [];
  try {
    events = await log.list();
  } catch (err) {
    console.error('[Shelfy] could not read the log', err);
  }

  const { caught, keptPct } = summarize(events);

  // A shelf that predates the log would otherwise read "0 caught" next to real books.
  if (!caught) {
    el.textContent = shelfCount ? `${shelfCount}` : '';
    return;
  }
  el.textContent = keptPct === null ? `${caught} caught` : `${caught} caught · ${keptPct}% kept`;
}

let filterText = '';

async function render(): Promise<void> {
  const app = document.getElementById('app');
  if (!app) return;

  let all: SavedBook[];
  let store: Store = 'amazon';
  try {
    [all, store] = await Promise.all([
      library.list(),
      readSettings().then((s) => s.store),
    ]);
  } catch (err) {
    console.error('[Shelfy] could not read the shelf', err);
    const failed = document.createElement('p');
    failed.className = 'empty';
    failed.textContent = "The shelf didn't load. Close this and open it again.";
    app.replaceChildren(failed);
    return;
  }

  void renderStats(all.length);
  const disclosure = document.getElementById('disclosure');
  if (disclosure) disclosure.hidden = all.length === 0;

  if (!all.length) {
    renderEmpty(app);
    return;
  }

  app.replaceChildren();

  // A search box on a shelf of four is chrome for its own sake.
  if (all.length > FILTER_FROM) {
    const filter = document.createElement('input');
    filter.id = 'filter';
    filter.type = 'search';
    filter.placeholder = `Find among ${all.length} books`;
    filter.value = filterText;
    filter.addEventListener('input', () => {
      filterText = filter.value.trim().toLowerCase();
      void render().then(() => document.getElementById('filter')?.focus());
    });
    app.appendChild(filter);
  }

  let index = 0;
  let shown = 0;
  for (const intent of INTENTS) {
    const group = all.filter((s) => s.intent === intent && matchesFilter(s, filterText));
    if (!group.length) continue;
    shown += group.length;

    const heading = document.createElement('h2');
    heading.append(LABELS[intent]);
    const n = document.createElement('span');
    n.className = 'n';
    n.textContent = `${group.length}`;
    heading.appendChild(n);
    app.appendChild(heading);

    group.forEach((saved) => {
      app.appendChild(renderBook(saved, index, store, () => void render()));
      index++;
    });
  }

  if (!shown) {
    const none = document.createElement('p');
    none.className = 'empty';
    none.textContent = `Nothing matches "${filterText}".`;
    app.appendChild(none);
  }
}

void render();

# Shelfy — Privacy Policy

_Last updated: 2026-07-29_

Shelfy keeps your reading list on your own computer. There is no Shelfy account, no

## What stays on your computer

- **Your shelf** — every book you save, its intent, and the link to the post you found it
  in. Stored in your browser's local extension storage and never transmitted.
- **The recognition log** — the most recent 200 attempts, so the shelf can show you how
  often it identified a book correctly. Never transmitted. Clear it any time from the
  options page.
- **Your API key**, if you add one. Sent only to the recognition provider you configured.

## What leaves your computer, and where it goes

- **To your recognition provider** (Google Gemini by default, or any endpoint you
  configure): the image you asked Shelfy to read, and the text of the post it appeared
  in. Sent only when you press the book button or use the right-click menu.
- **To openlibrary.org**: the recognized title and author, as a search query, to identify
  the book and fetch its cover. OpenLibrary is a project of the Internet Archive.

Nothing else is sent anywhere. Shelfy does not read your timeline, your account, or any
page you have not explicitly asked it to act on.

## Affiliate links

The **buy** link on a saved book is an affiliate link. If you buy through it, Shelfy may
earn a small commission at no extra cost to you. The links appear only on books you have
already chosen to save, they never change what Shelfy recommends, and no information
about you is sent when the page loads — only when you choose to click.

## Removing your data

Uninstalling Shelfy deletes everything it stored. The recognition log can be cleared
separately from the options page.

## Contact

Open an issue at https://github.com/MaxoCorrea/shelfy
